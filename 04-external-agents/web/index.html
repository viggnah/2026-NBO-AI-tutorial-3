Gateway - what the platform did

Nothing yet. Every request the agent makes to the model passes through Agent Manager's gateway; anything a policy does to it shows up here.

The agent holds no model credential. It calls the gateway, and the gateway holds the key, applies the policies and forwards the call.

Why masking is not shown here
A blocked response comes back to the agent, so this page can report it. PII masking is different: the gateway rewrites the request on its way to the model, and the agent never sees the substitution. Nothing reaches this page to display. To see it, ask the model directly through the gateway - the README has the call, and the model answers *****.
